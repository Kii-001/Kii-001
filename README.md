### 📋 𝗧𝗲𝗺𝗽𝗹𝗮𝘁𝗲 𝗚𝗶𝘁𝗛𝘂𝗯 𝗔𝗰𝘁𝗶𝗼𝗻𝘀

Buat file `.github/workflows/readme.yml`:

```yaml
name: Update README with animations

on:
  schedule:
    - cron: '0 0 * * *'
  workflow_dispatch:

jobs:
  update-readme:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: athul/waka-readme@master
        with:
          WAKATIME_API_KEY: ${{ secrets.WAKATIME_API_KEY }}
          SHOW_TITLE: true
          SHOW_TIME: true
          SHOW_MASKED_TIME: true
```

Jangan lupa tambahkan WakaTime API key ke repository secrets!

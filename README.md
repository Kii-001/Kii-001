## 🛠 Setup Instructions

To get a similar README for your profile:

1. Replace `YOUR_USERNAME` with your GitHub username

4. Customize the social media links

### Required GitHub Actions

Add this to your `.github/workflows/readme.yml`:

```yaml
name: Update README

on:
  schedule:
    - cron: '0 0 * * *'
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - uses: athul/waka-readme@master
        with:
          WAKATIME_API_KEY: ${{ secrets.WAKATIME_API_KEY }}
```

Remember to add your WakaTime API key to your repository secrets!
